| 组件                   | 作用                           | 通俗理解                            |
| ---------------------- | ------------------------------ | ----------------------------------- |
| State（状态）          | 全局共享数据载体，所有节点读写 | 工作流的 "全局数据库"               |
| Node（节点）           | 执行单元，封装业务逻辑         | 图中的 "站点"，每个站点做一件具体事 |
| Edge（边）             | 定义节点间执行顺序             | 站点间的 "道路"，分普通边和条件边   |
| Checkpointer（持久化） | 保存/恢复状态，支持断点续跑    | 工作流的 "存档点"                   |
