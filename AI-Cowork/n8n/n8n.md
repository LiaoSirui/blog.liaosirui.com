## n8n 简介

n8n 是一个开源、强大的工作流自动化工具，允许用户通过可视化方式连接不同的应用程序和服务。它将 AI 功能与业务流程自动化相结合，它可以帮助开发者和非技术人员创建复杂的工作流，实现数据在不同系统间的自动传输和处理

与其相同的竞品还有 Dify 由中国团队主导开发的工作流产品

| 维度        | Dify                   | n8n                                                          | LangGraph                          |
| :---------- | :--------------------- | :----------------------------------------------------------- | :--------------------------------- |
| 核心定位    | 低代码 LLM 应用工厂    | 可视化自动化 + Agent 编排（工作流）                          | 代码优先的 Agent 状态图框架        |
| 落地速度    | 快（应用级）           | 快（拖拽 + 模板 + 海量集成）                                 | 视团队代码能力                     |
| 控制粒度    | 中（应用参数化）       | 中等（可插代码/条件/子流程）                                 | 最高（显式图、状态、检查点）       |
| 多代理/记忆 | 有（应用内封装）       | 有（会话/外部向量库/RAG）                                    | 原生多智能体 + 检查点记忆 + 中断   |
| 集成生态    | 以 LLM 应用为主        | 500+ 预置 + 通用 HTTP + Webhook，对接 SaaS/DB/支付/邮件等    | 依托 LangChain 生态与 Python/TS 包 |
| 部署/开放性 | 开源 + 云              | 开源可自托管 + 云                                            | 开源库 + 商业平台                  |
| 对外变现    | 可将应用对外发布       | 工作流可暴露为 API/端点，内置鉴权/角色/日志，适合卖 “微型 SaaS/自动化服务” | 以代码/服务形态提供                |
| 典型适配    | “把 LLM 做成应用/面板” | “把 AI 接进业务流程”                                         | “工程化的复杂 Agent 系统”          |
