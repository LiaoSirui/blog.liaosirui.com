RHEL 默认的 `/etc/depmod.d/dist.conf` 是

```bash
search updates extra built-in weak-updates
```

按这个顺序,`kernel/`(built-in)本应优先于 `weak-updates`。但 mlnx-ofa_kernel 的 kmod 包会安装类似 `/etc/depmod.d/zz02-mlnx-ofa_kernel-*.conf` 的文件,里面有:

```bash
override cifs * weak-updates/mlnx-ofa_kernel/fs/cifs
```

`override` 优先级高于 `search`,所以 `modprobe cifs` 会选中 OFED 版本。

`weak-updates/...` 下的文件是链接,指向为其他 el9 内核编译的 `extra/mlnx-ofa_kernel/...`,由 `weak-modules` 根据 kABI 兼容性自动创建。

```bash
# 重建依赖
depmod -a $(uname -r)
```
